# Bank Info Management System

A modern, premium web application for managing and searching bank account details. Built with the MERN stack (MongoDB, Express, React, Node.js).

## ✨ Features

- **Premium UI**: Modern glassmorphism design with a responsive layout.
- **Real-time Updates**: Accounts appear in the list immediately after being added or updated without page refresh.
- **Smart Search**: Search by mobile number or account number.
- **Receipt Generation**: Generate and print professional receipts for transactions.
- **CRUD Operations**: Full support for adding, viewing, editing, and deleting account information.

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- MongoDB running locally or a MongoDB Atlas URI

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd bank-info-app
   ```

2. **Backend Setup**
   - Navigate to the `backend` folder.
   - Create a `.env` file (refer to `.env.example`).
   - Install dependencies and start:
     ```bash
     npm install
     npm start
     ```

3. **Frontend Setup**
   - Navigate to the `frontend` folder.
   - Install dependencies and start:
     ```bash
     npm install
     npm start
     ```

## 🛠️ Tech Stack

- **Frontend**: React, CSS (Vanilla with Modern Variables)
- **Backend**: Node.js, Express
- **Database**: MongoDB (Mongoose)
- **API**: Axios
